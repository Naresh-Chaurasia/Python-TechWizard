# ✔️ Agentic AI – 21 Day Self-Paced Program

## Program Outcome

By the end of this program, you will be able to:

- Understand the difference between traditional AI and Agentic AI
- Build AI agents that plan, reason, and act
- Integrate tools, memory, and decision-making
- Design multi-agent systems
- Handle real-world challenges like hallucination, failure, and scaling
- Build a production-ready agentic system

## 🚀 Getting Started

### For Local Viewing with Full Features

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Naresh-Chaurasia/Python-TechWizard.git
   cd Python-TechWizard/Agentic-AI-Reference-Implementation
   ```

2. **Install AsciiDoc processor:**
   ```bash
   # Install asciidoctor
   gem install asciidoctor
   
   # Or using npm
   npm install -g asciidoctor
   ```

3. **Render the full document:**
   ```bash
   asciidoctor docs/agentic-ai-self-learning.adoc
   ```

4. **Open the generated HTML:**
   ```bash
   open docs/agentic-ai-self-learning.html
   ```

### For GitHub Viewing

- Click on any day in the table above to view that specific day's content
- Each day is a standalone AsciiDoc file that renders properly on GitHub
